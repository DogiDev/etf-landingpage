# AI Log

Při práci na projektu používám Google Antigravity IDE pro návrh a implementaci aplikace.

Do této složky ukládám důležité části skutečných konverzací s AI, včetně zadaných pokynů a odpovědí agenta. Jednotlivé záznamy doplňuji vlastními poznámkami o tom, jak jsem návrhy vyhodnotil, co jsem ověřil a jaké případné chyby jsem našel a opravil.

Původní komunikaci odděluji od vlastních komentářů, aby bylo možné rozlišit výstup AI od mého úsudku.

Protože používám Antigravity místo Claude Code, nemohu použít příkaz Claude Code `/export`. Záznamy proto archivuji v Markdownu podle možností použitého nástroje.

Obsah této složky budu doplňovat průběžně podle skutečného průběhu vývoje.
